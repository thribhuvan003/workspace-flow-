# WorkspaceFlow

A production-grade, full-stack SaaS project management platform built with Next.js 16, TypeScript, Prisma v7, and Socket.io. Inspired by Linear + Notion + Plane.so.

**Live features:** Real-time Kanban board · Collaborative docs · Team management · Analytics · Stripe billing · Claude AI summaries · Slack/GitHub/Discord integrations · Command palette

---

## Tech Stack

| Layer | Technology |

## Features

### Core
- **Multi-tenant workspaces** — every query is scoped by `workspaceId` with membership verification
- **RBAC** — `OWNER | MEMBER | GUEST` roles enforced on every API route
- **Real-time Kanban** — drag-drop task board synced via Socket.io with presence indicators
- **Collaborative docs** — rich text editor with real-time socket updates
- **Live comments** — with typing indicators and activity log per task

### AI (Claude-powered)
- **Workspace summary** — executive summary, standup notes, or backlog analysis generated by Claude Opus
- **AI task descriptions** — one-click description generation using Claude Haiku
- Summaries stored in `AiSummary` table for history

### Integrations
- **Slack** — connect via bot token, notify channels on task events
- **GitHub** — link pull requests to tasks via personal access token
- **Discord** — send activity to Discord via webhook URL
- Integration credentials stored encrypted, never exposed in API responses

### Billing
- Stripe Checkout for Pro plan upgrades
- Stripe webhook handler for subscription lifecycle events
- Customer portal for self-serve plan management

### UX
- **Command palette** (Cmd+K / Ctrl+K) — instant navigation across all pages
- Dark mode by default
- Responsive sidebar with workspace switcher
- Toast notifications throughout
- Loading skeletons on all async pages

## Getting Started

### Prerequisites
- Node.js 20+
- PostgreSQL 15+
- Stripe account
- Anthropic API key (for AI features)
- Google and/or GitHub OAuth app

### 1. Clone & Install

```bash
git clone https://github.com/thribhuvan003/workspace-flow
cd workspace-flow
npm install
```

### 2. Environment Variables

Create `.env` in the project root:

```env
# Database
DATABASE_URL="postgresql://user:password@localhost:5432/workspaceflow"

# NextAuth
NEXTAUTH_URL="http://localhost:3000"
NEXTAUTH_SECRET="your-secret-32-chars-minimum"

# OAuth providers
GOOGLE_CLIENT_ID="..."
GOOGLE_CLIENT_SECRET="..."
GITHUB_CLIENT_ID="..."
GITHUB_CLIENT_SECRET="..."

# Stripe
STRIPE_SECRET_KEY="sk_test_..."
STRIPE_PUBLISHABLE_KEY="pk_test_..."
STRIPE_WEBHOOK_SECRET="whsec_..."
STRIPE_PRO_PRICE_ID="price_..."
NEXT_PUBLIC_STRIPE_PUBLISHABLE_KEY="pk_test_..."

# Anthropic (for AI features)
ANTHROPIC_API_KEY="sk-ant-..."

# App
NEXT_PUBLIC_APP_URL="http://localhost:3000"
```

### 3. Database Setup

```bash
# Push schema to database
npm run db:push

# (Optional) Open Prisma Studio
npm run db:studio
```

### 4. Run Development Server

```bash
npm run dev
```

This starts the custom Socket.io + Next.js combined server on port 3000.

## Key Architecture Decisions

### Prisma v7 Driver Adapter
Prisma v7 removed the `url` field from `datasource` blocks. The app uses `@prisma/adapter-pg` with a `pg.Pool` for the connection:

```typescript
// src/lib/prisma.ts
const pool = new pg.Pool({ connectionString: process.env.DATABASE_URL! });
const adapter = new PrismaPg(pool);
export const prisma = new PrismaClient({ adapter });
```

### Custom Socket.io Server
Next.js doesn't support WebSockets natively in App Router. A custom `server.ts` wraps Next.js with an HTTP server and Socket.io:

```bash
npm run dev  # runs: tsx server.ts
```

### Multi-tenancy Security
Every API route checks workspace membership before any data operation:

```typescript
const access = await prisma.workspaceMember.findUnique({
  where: { userId_workspaceId: { userId, workspaceId } },
});
if (!access) return NextResponse.json({ error: "Forbidden" }, { status: 403 });
```

Sensitive operations (invite, integration config, member removal) additionally check `role === "OWNER"`.

### Real-time Events
Socket.io workspace rooms (`workspace:${workspaceId}`) broadcast:
- `task-moved` — Kanban column changes
- `task-created` — new task added
- `comment-added` — new comment
- `doc-updated` — document content change
- `typing-start/stop` — presence indicators

## Stripe Webhook Setup

```bash
# Install Stripe CLI
stripe listen --forward-to localhost:3000/api/stripe/webhook
```

Events handled: `checkout.session.completed`, `customer.subscription.updated`, `customer.subscription.deleted`

## Deployment

The app is designed for deployment on any Node.js host (Railway, Render, Fly.io, AWS EC2). For Vercel, Socket.io requires a separate WebSocket server due to serverless limitations.

```bash
npm run build
npm start
```

Make sure `DATABASE_URL` and all environment variables are configured in the deployment environment.
